# Bencho Now playing source

Adapted from the actual production implementation served on 2026-09-12:

- Demo: https://bencho.dev/?c=sound&theme=dark
- JavaScript: https://bencho.dev/assets/index-O7JKZZmz.js (Sound implementation `iy`, tween `Nv`, play mark `ty`)
- CSS: https://bencho.dev/assets/index-B2qFwCFP.css (`.snd-*` player rules)
- Source metadata in that bundle: `github.com/lorenzo04us/Bencho`, `src/lab/Sound.tsx`
- License: https://bencho.dev/licence

The repository API returns 404. This is a readable adaptation of the deployed code, not a claim to have obtained the unpublished TSX. Preserved: 260px width, 78→189px height, Morph 50 (460ms quart-out), Corner 16, the independent closing scale, continuous sleeve geometry, delayed detail reveal, play/pause polygon morph, and click-away collapse. Arc provides its existing track/audio state, previous/next, loading status, theme colors, and real seeking; the demo's fake playback timer and sound effects are omitted. The heart retains the demo's session-local state.
